# 本地补充验收

通用门禁参照 `../SKILL.md`，用户偏好参照 `user-preferences.md`。

在既有产品新增设置、管理等功能时：

- 已读取原界面的颜色变量、字体、间距、边框、按钮与图标。
- 新功能沿用原有视觉系统，没有引入独立主题。
- 操作图标使用现有 SVG 或同一图标体系，不使用字符、emoji 或几何符号凑图标。
- 用户要求 icon 入口时，入口仅显示图标，且有 tooltip 与无障碍名称。
- 已在原产品上下文中查看实际截图，并检查桌面与窄屏布局。

- 原生 dialog 已显式定义居中定位，并在加载产品全局 CSS 的测试中验证中心位置、短视口和隐藏状态。
