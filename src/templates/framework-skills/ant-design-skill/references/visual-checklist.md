# Visual Prototype Checklist

输出前快速检查，不做生产级 QA。

## 5 秒测试

- 一眼知道页面是什么吗？
- 一眼知道最重要内容在哪吗？
- 一眼知道主操作是什么吗？

## 信息架构

- 主内容只有一个视觉中心
- 没有为了填满屏幕而添加无意义区块
- 不存在重复标题
- Tab / Card 分组都具有明确语义

## 数据真实感

- 没有 Test 1 / User A / Lorem Ipsum
- 状态存在合理差异
- 时间、金额、人数、进度合理
- 数据能体现业务场景

## 视觉

- 页面边距一致
- Card 不重复套 Card
- 表格操作不换行
- 长文本不会破坏布局
- 状态色克制
- 页面没有大片无意义留白

## 交互

- 主按钮可点击
- Drawer / Modal 能正常打开关闭
- 关键操作有 message / 状态反馈
- Demo 不出现明显死按钮（纯装饰按钮除外）

满足以上即可交付。
