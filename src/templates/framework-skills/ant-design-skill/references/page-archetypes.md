# Page Archetypes

页面类型用于决定整体信息架构，而不是限制具体组件。**一个原型可以包含多个 Page Archetype**：例如 Data Management → Object Detail → Settings。先决定页面流，再为每个页面选择最合适的 archetype。

不要为了坚持单页，把本应独立的详情、配置、编辑或流程工作区全部塞进 Tab / Drawer。拆页是否必要，见 `prototype-flow.md`。

## 1. Data Management / 数据管理页

**适用**：客户、用户、订单、直播、任务、内容、资源、设备等对象集合。

推荐结构：

1. 标题 + 主操作
2. 可选状态汇总 / Tab（确有分类价值时）
3. 搜索 / 筛选 / Toolbar
4. Table / List 主区
5. Drawer / Modal 处理单个对象

典型主操作：新增、导入、创建任务。

不要默认加 Dashboard。

## 2. Object Detail / 对象详情页

**适用**：客户详情、订单详情、直播详情、项目详情、员工详情。

推荐结构：

1. 返回 + 对象名称 + 状态 + 主要操作
2. 3～5 个关键摘要
3. 基础信息
4. 1～3 个业务语义分组
5. Timeline / 操作记录 / 关联对象（真正需要时）

详情页不能退化为几十个字段平铺。

## 3. Create & Edit / 创建编辑页

**适用**：新增业务对象、复杂配置、发布流程。

推荐结构：

1. 明确标题与当前目标
2. 按语义分组的 Form
3. 复杂流程才用 Steps
4. 固定清晰的保存 / 提交操作

3 步以内优先横向 Steps；4 步及以上或步骤说明长时优先竖向。

## 4. Dashboard / 数据看板

**适用**：经营数据、系统状态、运营效果、成本与增长分析。

推荐结构：

1. 范围 / 时间控制
2. 3～5 个核心 KPI
3. 1 个主趋势图
4. 最多 1 个构成 / 排名 / 异常辅助区

每个 KPI 都要能回答一个业务问题。

## 5. Project Workspace / 项目工作台

**适用**：视频处理、AI 拆条、翻译项目、任务执行、分析流程、编辑工作区。

推荐结构：

1. 项目标题、状态、进度、主操作
2. 原始输入 / 对象信息
3. 主工作区：结果、片段、步骤、任务
4. 属性 / 运行状态 / 辅助设置
5. Drawer / Modal 编辑局部对象

重点展示“当前正在处理什么”和“结果是什么”。

## 6. Analysis Result / 分析结果页

**适用**：AI 分析、检测报告、审核结果、数据诊断。

推荐结构：

1. 分析对象 + 完成状态
2. 结论摘要
3. 核心指标 / 风险等级
4. 详细结果分组
5. 原始证据 / 引用 / 明细
6. 导出 / 重新分析

先结论，后证据。

## 7. Settings / 配置页

**适用**：产品设置、通知、模型参数、权限偏好、工作流设置。

推荐结构：

1. 标题
2. 左侧锚点 / Menu（只有配置组很多时）
3. 2～5 个设置组
4. 即时保存或底部统一保存

设置按用户心智分组，不按数据表字段分组。

## 8. Approval / 审批处理页

**适用**：审核、审批、风控、工单处理。

推荐结构：

1. 申请对象与状态
2. 核心信息摘要
3. 申请内容 / 证据
4. 历史审批 Timeline
5. 固定的通过 / 驳回 / 补充材料操作

决策按钮必须明显。

## 9. Monitoring / 监控页

**适用**：服务器、直播链路、任务运行、告警、服务状态。

推荐结构：

1. 当前整体状态
2. 必要的健康指标
3. 主趋势 / 实时状态
4. 告警 / 异常列表
5. 对象明细

颜色只用于状态，不要把每个指标都做成不同颜色。

## 10. Content Management / 内容管理页

**适用**：文章、视频、素材、书籍、课程、内容审核。

可根据视觉素材比例选择 Table / List / Card Grid。

重点字段：封面、标题、状态、作者/来源、更新时间、关键业务指标、操作。

## 11. AI Workspace / AI 工作台

**适用**：Agent、智能问答、Copilot、AI 分析助手、多步骤智能任务。

推荐结构：

1. 当前会话 / 业务对象上下文
2. 消息 / 任务主区
3. 输入区域
4. Agent 状态 / 步骤（只有产品价值需要展示时）
5. 引用资料 / 结果侧栏（需要时）

AI 页面不能只剩“ChatGPT clone”；必须体现该垂类产品独有的信息和动作。

## 12. File / Resource Management / 文件资源页

推荐结构：

1. 路径 / 分类上下文
2. 上传 / 新建
3. 搜索、类型、时间等筛选
4. Table / Grid
5. 预览 / 详情 Drawer
