# 页面级无限画布 · 编辑器运行时 5

## 画板固定状态（运行时 37）

激活画板（双击进入预览/试用）后，画板上方标题行右端出现灰色图钉，用于「固定当前状态」；未激活的画板不显示图钉。已固定时点开菜单可更新、以当前状态复制、回到固定状态或取消固定；右键及命令面板也提供相同操作。Esc 退出激活并恢复固定状态；临时试用不覆盖保存值。固定状态是节点 `pinnedState`，与位置锁定及业务版本分开，随画布保存、复制、下载和分享。`board-state.js` 是必需编辑器资源。

**生成或修改业务画板时必须实现状态契约**：

```js
window.ProtaBoardState = {
  version: 1, // 状态结构发生不兼容变化时递增
  capture() { return structuredClone(appState); },
  restore(data) { appState = structuredClone(data); render(); }
};
```

`capture` 返回纯 JSON 数据（最多 256 KB），包含当前页面、标签、弹窗、筛选、校验信息及展示所需演示数据；不能只捕获 DOM，也不要保存凭证和密码。允许异步，4 秒内完成。`restore` 必须完整替换状态并完成渲染，不能重放点击、表单提交、发送验证码或其他业务请求。状态结构要独立于画板路径和实例 ID，复制后仍能使用。表单、details 和滚动位置由编辑器补充保存；受控表单的值仍须包含在业务状态中。画板内页面跳转须留在当前画板目录内，路由随实例重新定位。

旧的普通 JS 画板若具有顶层 `state` 对象和 `render()`，编辑器尝试自动接入；组件闭包、模块和其他结构不做猜测，使用「适配状态保存」进入已有 Agent 并填入适配任务草稿，由用户发送。固定前执行一次恢复校验，失败保留原固定状态；恢复失败显示可操作提示，不静默覆盖。取消固定及固定更新支持原有撤销重做；只读分享只能查看和试用，不能改变固定状态。

完整复制本目录到工作区 `src/pages/{projectId}/{pageId}/{version}/`。注册一个顶层页面：`targetDevice: "canvas"`、`pageMode: "infinite-canvas"`。旧的 canvas-frame 保持不变。

界面为「画布即主界面」：无常驻侧栏、图层面板或设计 Tab；左上角是画布名称与自动保存状态，右上角是撤销 / 重做 / 全屏，底部是悬浮胶囊创作工具栏与缩放条；所有对象操作由选中后的上下文工具栏、右键菜单、属性气泡和 ⌘K 命令面板承担。图标为本地内联的 Lucide v0.544.0（ISC License, © Lucide Contributors）。

## 页面与画板

画布是页面，不是项目总览。内部画板、组件、素材不注册为顶层页面。业务界面位于本版本 `boards/{节点ID}/index.html`、`styles.css`、`app.js`，在画板节点的 src 中关联。Agent 负责自动创建和关联，不要求用户填写文件路径。index.html、styles.css、app.js、canvas-core.js、icons.js、marked.js、markdown.js 是编辑器运行文件，不要改成业务页面。

`canvas-data.js` 是布局源文件：`window.PROTA_CANVAS = { ... };`，支持 file:// 和静态分享，不需要构建。顶层含 schemaVersion=1、revision、nodes、viewport。保持文件为纯 JSON 赋值，不加入执行逻辑。

节点有稳定 id、type（board/group/text/note/rect/ellipse/image）、name、x、y、width、height。可选 parentId、text、color、textColor、fontSize、fontWeight、textAlign、padding、opacity、radius、locked、src。**坐标始终是世界坐标**，parentId 表示容纳关系，不能形成循环。数组顺序决定绘制顺序。分组包围盒由子级计算，改变分组位置会移动整个子树。移动画板也会移动子级；移动对象进入 / 移出画板会更新归属。

图片拖入或粘贴后先临时嵌入，保存时服务端以内容哈希写入当前版本 assets/，更新节点引用，降低布局文件和撤销记录大小。单张上限 4 MB。外部 assets 引用必须是本版本相对路径。

复制已有业务画板会复制其代码目录，副本拥有独立 src。group 复制会重新映射所有后代 ID 与 parentId。按钮、输入框、信息卡、导航栏是可编辑的组合素材，属于设计对象；可运行的业务交互由 Agent 在画板 HTML 中实现。

## 统一操作与上下文

右键菜单、属性气泡和命令面板打开时收起选中工具栏，关闭后根据有效选择恢复。「更多」与「更多对齐」菜单保留原有工具栏，在其下方展开，并随工具栏位置更新；菜单过长时内部滚动。再次点击同一入口或点击空白处收起菜单，保留工具栏与选择。各浮层互斥，关闭菜单不清空选择。

浮动工具栏、右键菜单、命令面板和快捷键共用同一套 Action 定义（id、名称、图标、快捷键、可用条件、执行）。单选文本 / 便签 / 形状 / 图片 / 未生成画板 / 已生成画板 / 分组分别展示对应的主要操作（Icon + 文案按钮），层级（置顶 / 置底）与聚焦固定在一级；文字编辑由双击进入，不在工具栏出现。多选时显示「已选 N 个」，编组、居左 / 水平居中 / 居右对齐在一级，其余对齐与等距收进「更多对齐」二级菜单（右键菜单与命令面板仍提供完整对齐菜单），共用一个选择框与一套操作；其余低频操作进入「更多」菜单。已锁定对象只显示解锁与聚焦。

选区变换是统一的：单选与多选共享一个选区框和 8 向手柄，多选按选区整体比例同时变换成员位置与尺寸，Shift 保持比例与对侧锚点。Alt 单击不复制；超过 3 CSS px 拖拽阈值后才创建副本，副本不产生额外偏移。一条连续拖拽只占一条撤销记录；Esc、Pointer Cancel 与捕获丢失均回滚未完成操作，包括新建对象、Alt 副本、选择、撤销 / 重做栈和本机草稿。

## 编辑操作

- V 选择、H 抓手、T 文本、R 矩形、O 圆形、F 自由画板。绘制工具可拖出尺寸，或使用添加菜单。
- 空格拖动 / 中键平移，普通滚轮上下平移，触控板横向滚动或 Shift + 滚轮横向平移。在 Portal 其他区域（如 Agent 面板）按下空格同样生效，按下画布对象后才补按空格时，未开始的拖动会转为平移。触控板双指缩放、Ctrl / Cmd + 滚轮（含驱动映射的缩放滚轮）以鼠标位置为中心缩放。缩放按钮和比例菜单沿用鼠标最后所在的画布点，触屏双指缩放。缩放范围 5%–400%，缩放条点击百分比可弹比例菜单（50–200% 与适配全部），适配 / 聚焦带平滑过渡。
- 框选仅选中完整包含在选框内的对象（任意拖动方向），支持 Shift 追加多选，Shift 保持宽高比 / 移动方向，Alt 拖动复制与暂时关闭吸附。
- 对齐辅助线、对齐与等距分布菜单、方向键移动（Shift 步长 10）、图层排序、锁定、F2 重命名；重命名面板仅显示名称，画板额外显示设备预设。
- 右键空白处：「添加到这里」分组创建菜单（画板子菜单、文本、便签、形状、图片）、粘贴、查看全部，新对象出现在右键位置；右键对象（含多选之一）显示该类型对应操作。
- Ctrl / Cmd + G 分组，Shift + Ctrl / Cmd + G 取消分组；Ctrl / Cmd + D 复制；Ctrl / Cmd + C/V 复制粘贴，剪贴板持久化到本机，文本 / 基础组件可跨画布粘贴并重映射 ID；含业务文件或 assets 引用的跨画布粘贴会明确提示暂不支持，避免生成失效引用。
- 单选图片后，Shift + Ctrl / Cmd + C 或「复制到剪贴板」将原图按原始像素尺寸转为 PNG 写入系统剪贴板（GIF 为静态帧），可粘贴到其他应用；不新增画布对象。需 HTTPS 或本机地址及剪贴板写入权限；锁定图片也可复制。
- Ctrl / Cmd + K 命令面板：搜索创建、对齐、缩放、全屏、Agent 等命令；↑↓ 选择、Enter 执行、Esc 关闭。
- 选择模式下双击空白处，在点击位置新增文本并立即编辑；抓手、空格平移、只读或 Agent 执行时不创建。
- 拖入的 Markdown 文档使用独立的文档编辑交互：Tab / Shift+Tab 按整行缩进 / 退级（四空格，可多选），Enter 续写列表、递增有序编号、重置新任务状态；空列表项退出或逐层退级，引用自动续写，代码围栏内不误续写列表，Shift+Enter 只换行。格式工具支持切换及原生撤销重做。拖入本地 `.md` / `.markdown` 生成普通文本对象，与普通文本框分开处理；从 PRD 拖入仍关联原文件并保留并发保护。
- 导入的文档支持 Markdown（标题、粗斜体、删除线、列表、任务列表、引用、代码块、链接、图片、表格）。通过「编辑 Markdown」编辑源文，失焦显示排版，Esc 恢复原文；原始 HTML 作为文字显示，不执行。解析器 Marked v16.4.1 随版本本地打包（MIT，见 LICENSE.marked），无需网络。
- 双击普通文本、Markdown 文档、便签直接原位编辑，保持当前视口，点击外部保存，Esc 取消。双击其他对象直接聚焦；聚焦时任意位置单击右键等待 420ms 后退出，期间双击右键进入当前画板标注，不打开菜单；双击画板同时激活并聚焦；激活后仍可双指缩放或 Ctrl / Cmd + 滚轮缩放画布，缩放按钮保持画板激活，画板内部滚动和侧边滚动条继续可用，Esc 回到画布。分组通过「进入分组」操作进入组内编辑（其余对象淡化），Esc 返回组外。完整的多层选择路径仍待完善。
- 文本与便签宽度固定、高度随内容自适应：输入、Markdown 换行、字号与对齐变化、拖动左右手柄或角手柄改变宽度后都重新测量，内容多也不会被裁切，也无需手动拖高度。上下手柄只改变位置不改变高度；新增文本先给定写作宽度，再用左右手柄调整；属性面板的高度只显示不可编辑。高度由内容决定，画板与分组的包围盒随测量结果更新，撤销重做与保存沿用原有记录。

验证：`node tests/canvas-text-autofit.browser.mjs`。
- Esc 优先级：关闭菜单 / 面板 → 取消拖拽 → 结束文本编辑 → 退出预览或分组 → 取消选择。
- 便签有色板，文本有排版（字重 / 对齐），画板有设备预设，图片可替换与适应比例。
- 支持 60 步本地撤销重做。接收外部更新后清空旧撤销栈，避免用旧状态覆盖新结果；Agent 结束的合并保留合并前一步撤销。

## Agent 工作流

底部工具栏的 Agent 按钮、选中对象工具栏的「Agent 修改 / 生成」、空画板入口和命令面板均指向现有 Portal Agent 会话，画布内没有第二套 Agent 系统。未选对象表示整张页面，选择对象后自动显示作用范围。

发送前保存当前文档，保存失败时不启动 Agent。任务准备和执行期间，仅保护开始时选中的对象、其子对象及包含它们的容器；其他画板和元素仍可新增、移动、调整属性和删除。未选择对象时不全局锁定画布。保护随任务结束释放，标注和查看保持可用。运行期间手动修改实时写入服务器的持久化字段记录，与 Agent 的独立改动自动合并；后台协调在离开画布或重启服务后仍可恢复手动修改。Agent 修改业务画板代码后刷新其 iframe，普通选择、拖动和属性调整不重载画板。

## 保存与恢复

结构或文本编辑停止 100 ms 后自动保存到本机；文本无需退出编辑，中文组合输入完成前仅保留恢复草稿（无保存 / 导出按钮，⌘S 可手动触发）。本机接口 `/api/canvas/save` 的自动保存按 baseline 提取手动修改字段并应用到最新布局，独立修改自动合并；显式事务以完整 baseline 与 revision 检查并发，原子替换布局文件。完成素材处理后、替换布局前再次检查磁盘内容，避免处理中途的 Agent 写入被覆盖。每次保存保留最近 10 个布局历史文件到 `.canvas-history/`，不进入分享或 ZIP。

浏览器维护当前文档的本机恢复草稿；重新打开时独立修改自动合并，不创建冲突备份。真正的同字段冲突才提供恢复选择，恢复并成功保存后清理对应冲突备份，避免旧提示反复出现。关闭旧备份提示后记住关闭状态，同一份备份不再随刷新弹出；「保留当前状态」仅丢弃这份旧备份，不恢复或保存任何备份内容。保存失败提示重试；保存冲突时提供两个入口：「恢复我的修改」（以原基线、本机草稿、最新磁盘内容做三方字段合并，保留独立的外部修改；双方修改同一字段时再次确认后采用本机值，保存增加布局 revision，不新增页面版本）和「读取最新版本」（本机修改备份后读取外部版本，仍保留「恢复备份」入口），本机修改不会静默丢失。视角单独记忆在当前浏览器会话中，首次打开自动适配全部内容。

Portal 检测旧运行时（< 4）或不完整的编辑器资源后，修复当前打开的无限画布编辑器；即使初始化失败、没有 protaCanvas API，也能修复，保留 canvas-data.js、boards/、assets/，原运行文件备份在 `.canvas-runtime-backup/`。升级同步包含 icons.js 和 LICENSE.lucide。安装前检查完整资源包、先暂存全部文件再安装依赖，最后替换 HTML。每个画布自动修复最多尝试一次，避免循环重载；失败时显示独立于编辑器脚本的启动错误提示，允许重新加载或手动修复。只读分享不触发升级。工作区切换期间禁止保存和升级。

迭代、分享和 ZIP 包含整个版本。分享只读，保留平移、缩放和画板交互；独立静态文件可临时编辑并保留本机草稿，但无法直接写回磁盘。

## Schema v2 兼容数据内核（S1）

编辑器先同步启动，再通过本机 `/api/canvas/features` 读取工作区迁移开关（默认启用，可在工作区配置中显式关闭）。启用后，v1 只在内存补齐稳定 boardId 与空 boardRevisionId，首次编辑保存才在同次提交中备份原文件到 `.canvas-migrations/` 并写 v2。boardRevisionId 为 null 表示尚无正式业务快照，不等同于自动保存 revision。关闭开关后仍完整读写既有 v2，禁止旧客户端降级覆盖。

`canvas-domain.js` 是 v1/v2 校验、迁移注册表与节点/父子/逻辑画板索引的纯数据层，必须与 canvas-core.js 一起复制。迁移跨 vN 保持逻辑身份；独立复制生成新 boardId 并保留 originBoardId。未知可选字段及 edges 在保存/恢复时保留。HTML、修复资源清单和 Portal 健康判断均检查此依赖。完整契约与验证见产品文档 `docs/canvas-upgrade/s1-domain.md`。

## 画板业务版本存储（S2）

画板版本默认启用。名称旁显示当前版本（初始为 V1），下拉与页面版本保持相同结构：版本倒序、当前项高亮，每行可切换、基于该版本迭代或删除，底部提供「基于 Vx 迭代」。只剩一个版本时禁用删除，删除需要确认。迭代仅复制所选版本并切换到新版本，不自动打开 Agent。版本号递增且不复用删除过的编号。

业务版本以 `board-history/index.json` 中的 `versions` 映射管理，节点 `boardVersionId` 标识当前业务版本。切换会先保存离开版本的最新内容，再加载目标版本；不增加可见版本，也不改变其他画板和布局。底层不可变快照及恢复材料继续保留，用于事务恢复，不作为下拉中的新版本展示。旧快照历史自动映射为版本，读取时不写盘。

保存、复制、图片写入和版本操作共用页面文件锁与事务日志；中断恢复先保留原始材料，`.board-trash/` 不自动删除。普通自动保存不创建业务版本。损坏草稿单独留在事务恢复目录，不发布为可运行版本；共享资源冲突时拒绝覆盖。普通布局撤销不回退业务源码。旧快照 API 仍保留；下拉使用 `/api/boards/versions/manage` 的 `fork`、`switch`、`delete` 操作。


## 原生连线与自动寻路

`canvas-connections.js` 是编辑器依赖，必须与运行时一起复制。使用底部「连线」或 L，然后点击两个对象，也可从起点拖到终点；Esc / Pointer Cancel 取消未完成连线。点击两个对象会自动选择端点和避障路径；从四边圆点拖出可指定连接边。选中后用紧凑工具条编辑文字、选择线条样式、反向或删除；连线获得焦点后按 Delete / Backspace 也可删除，双击连线直接编辑文字。拖动两端手柄到对象上可自动重连，拖到圆点可固定连接边；手动连接后可一键恢复自动。操作共用画布的撤销、保存、冲突恢复与只读权限。

连线保存为文档 `edges`，适用于 v1 与 v2：`{ id, fromInstanceId, toInstanceId, label, kind, fromPort, toPort }`。`kind` 为 `main` / `secondary` / `exception`，端点为 `auto` / `left` / `right` / `top` / `bottom`。不保存手写折点。移动、缩放对象后，运行时重新计算连接边与正交路线：避开画板、标题、文本和卡片；容纳其他对象的矩形背景不挡路；用长度、转弯和交叉代价选择路径。标签按可用通道换行，避开对象与其他标签。对象完全重叠而无可用路径时显示“连接被遮挡”，不强行穿过界面。

删除对象会删除相连边，撤销一并恢复；复制多个对象、复制分组、Alt 拖动和剪贴板粘贴会重建所复制范围内的内部连线 ID。单独复制一个端点不复制跨范围关系。缺失端点的历史数据保留身份而不绘制虚假连线。

可选 `sections: [{ id, label, nodeIds }]` 自动生成区域导航；`initialFocusNodeIds` 定义首次打开聚焦的主流程，`focusAlignment: "top"` 可用于流程概览。已有浏览器会话视角继续保留。通用 API：`protaCanvas.connections.create(fromId, toId, options)`、`update(edgeId, changes)`、`getRoutes()`；`protaCanvas.focus(nodeIds)` 聚焦指定对象。布局源与关系保存在同一份 `canvas-data.js`，分享、下载、修复均使用相同原生功能。

验证：`node --test tests/canvas-connections.test.mjs`、`node tests/canvas-connections.browser.mjs`，并保留原画布全流程浏览器回归。

### 连线交互版本 7

端点仅使用对象上下左右四边的准确中点；自动寻路选择哪一侧，但不再偏移端点。选中和悬停只更新视觉状态，不重建连线 DOM；每次画板重绘均同步背景层级，避免点击后连线被分区背景遮住。

双击连线任意位置或文字可直接原位编辑，空文案同样支持。Enter 保存，Shift+Enter 换行，Esc 取消，点击外部保存；支持中文组合输入。选中连线后 Enter / F2 也可编辑，同一次文字修改只产生一条撤销记录。工具条提供文字、直观线条预览、反向和删除，不使用端点配置下拉框；指定连接边后可一键恢复自动。

连线工具下悬停对象显示四个中点连接点；拖动时高亮可用目标并显示吸附预览，端点重连保留原连线身份。取消拖动不会改变关系。连线获得焦点后可用 Delete / Backspace 删除；兼容中文输入法组合态与吞掉 keydown 的情况。`CanvasConnections.editorVersion >= 19` 用于 Portal 检查与自动升级（版本 8 起流程图端点落在真实轮廓上，见「流程图快捷创建」）。


连线默认是灰色实线（`kind: "main"`）；工具条保留「灰色实线」与「橙色虚线」两个预设，去掉绿色实线。第三个控件是配色面板：11 个预选色点选即生效，最后一格是一整块彩虹（白环、描边与预选格同宽同大小），打开系统取色器做任意颜色；当前自定义色显示在工具条的颜色按钮上；颜色写在，写入边的可选字段 `color`（`#RGB` / `#RRGGBB`，前后端同语义校验），箭头和连线文字跟随该颜色，虚线样式保持不变；点击任一套餐会清除自定义颜色。旧文档里的 `kind: "secondary"` 按灰色渲染，`kind` 枚举不变。

选择工具下不再显示四边连接点，改由流程图快捷创建的圆点承担；连线工具（L）仍保留悬停连接点与「点击 A → 点击 B」的连接方式。可见圆点使用独立热区，鼠标吸附半径 22 屏幕像素、触控 28 屏幕像素，不随缩放缩小；选中端点始终位于普通连接点之上。

创建、预览与改接共用穿透覆盖层的目标识别和寻路判断。端点拖动不足 4 屏幕像素不修改数据；松开空白、原固定端、锁定对象或无法寻路的位置保留原关系。Esc、pointercancel、丢失指针捕获、窗口失焦与切换只读均清理临时状态；改接保留连线 ID，整次修改只占一步撤销。被遮挡的旧连线仍显示可改接端点。

拖动接近画布边缘时连续平移，取消或松手立即停止。窄间距优先减少避障留白，仍不穿过对象本体。关联控件的画板会主动加载，使屏幕外端点在重新打开后仍能解析。

回归：`node tests/canvas-connection-gestures.browser.mjs` 覆盖真实鼠标/触控拖动、双向改接、热区、抖动、无效落点、取消、快速松手、边缘平移、缩放、持久化与只读切换。

### 控件连接点（连线编辑器 3）

进入连线工具（L），悬停画板内的按钮、链接、输入框、选择器或带 `data-connection-anchor` 的元素，可从控件四边连接点拖到其他画板或控件。空白区域仍沿用画板连接点。连接模式拦截控件点击，不触发业务提交；退出后可双击画板进行业务交互。

`edges` 的可选 `fromAnchor` / `toAnchor` 保存 `{selector, tag, text, page, src}`；不保存输入值。定位必须唯一，并匹配画板路径、页面标识、控件类型及标签。控件消失、被遮挡、滚出内部容器、页面切换或不可访问时，整条线隐藏，连接关系保留；原页面和控件恢复后重新显示。绝不退回画板边缘或任意同名控件。只支持可访问的同源业务画板，旧画板级连线保持原行为。

页面标识取当前路径、hash、标题与表单结构；需要区分同标题同结构的业务视图时，应给视图独立 hash 或不同表单 ID。端点随控件布局、画板缩放和滚动更新。自动保存、撤销重做、反向与端点重连沿用原连线机制。

验证：`node --test tests/canvas-connections.test.mjs`、`node tests/canvas-control-connections.browser.mjs`、`node tests/canvas-connections.browser.mjs`。


### 直接调整折线

选中连线后，每段中点显示小方形手柄；也可直接拖动线条任意位置。横段上下拖，竖段左右拖；首尾线段拖动会补出折弯，保持端点。拖动时显示实时路径和文字预览，吸附画板边缘、中线、其他连线与 10 单位网格；吸附阈值按屏幕像素计算，缩放后手感保持一致。Alt 临时暂停吸附，Esc / Pointer Cancel / 失焦取消。松手才提交，一次拖动对应一次撤销。

可选 `manualRoute: [{x,y}, ...]` 保存完整正交路径，最多 256 点；节点移动后调整端部，整体移动与复制时平移路径。自动连接按钮清除手动路径，端点重连重新自动寻路，反向同时翻转路径。底栏连线图标使用轻量直角折线箭头。

验证：`node tests/canvas-segment-connections.browser.mjs`、`node --test tests/canvas-connections.test.mjs`、`python3 -m unittest tests.test_canvas_store`。

### 从 PRD 弹窗拖入文档

拖动弹窗顶部文件名或文档列表中的文件名到画布，创建与原 PRD 关联的 Markdown 对象。节点的 prdPath 保存原文档路径，text 保留初始正文供离线使用。当前工作区每 2 秒检查原文；原文保存（含外部编辑）后自动刷新，保留位置、宽度、选择、连线与视角，不产生布局保存冲突。暂时无法读取原文时保留上次成功内容，原文恢复后自动继续同步。静态分享使用缓存正文，不请求原工作区。

标题、表格、列表、代码块和相对图片路径正常渲染，宽度可调整、高度自适应，拖入支持撤销和自动保存。普通文本与关联 PRD 共用 CanvasMarkdown 渲染器和 CanvasMarkdownEditor 编辑工具。双击原位编辑，工具条提供标题、粗斜体、列表、任务、引用、代码、链接和表格；「展开编辑」提供源码 / 双栏实时预览 / 预览模式，支持格式快捷键、列表续写、Tab 缩进、原生编辑撤销和取消。关联 PRD 保存会写回原文，并在客户端与服务端检查原文是否发生变化；冲突时保留草稿，不覆盖新内容。旧版拖入产生的 markdownSource 节点自动按关联文档处理。

Portal 在拖拽期间提供跨 iframe 接收层，避免内嵌业务画板吞掉拖放；旧运行时在落下时先升级再插入。只读或 Agent 任务准备期间明确提示不可拖入；Agent 执行期间拖入视同新增，任务结束后随合并一并保存。运行时版本 13 起支持，升级保留 canvas-data.js、boards/、assets/。验证：node tests/prd-canvas-drop.browser.mjs。

Markdown 编辑器运行时 15：渲染器与编辑器共同打包在 markdown.js 中。渲染和双栏预览使用完全相同的安全 Markdown DOM 与排版样式；关联原文的轮询在编辑期间暂停。

底部「流程图」提供开始/结束、流程矩形、判断菱形、子流程和连接圆点；右键空白处与命令面板同样支持插入。默认在选中对象旁放置并避开既有内容，保持为独立对象，不自动嵌入画板。

### 流程图快捷创建（运行时 49 · 连线编辑器 19）

选择工具下，悬停或单选任一可编辑对象（流程图形状、矩形、圆形、便签、画板、图片）都会在四边外侧显示四个圆点，悬停与选中表现一致：圆点本身可直接点击，悬停时变为带方向箭头的按钮。圆点浮在轮廓外 24 屏幕像素，与选中框的边缩放手柄留出间隔；对象过小、圆点会互相重叠时隐藏，仍可用 L 工具或「流程图」面板。顶部圆点会避开可见的对象标题。多选、锁定、Agent 保护、文字编辑、标注、抓手与只读状态不显示。

- 单击圆点：在该方向添加同类的对象——流程图形状按「同形状、同尺寸、同填充 / 描边 / 字体」复制，文字留空（显示占位提示）；便签、普通矩形、圆形、画板、文本和图片则在圆点旁打开流程图面板，选择后才创建。新对象都从该边连到对边并随后选中。
- 从圆点拖到已有对象：只新增一条连线，不弹面板。
- 拖到画布空白处：释放时不写入任何数据，箭头临时指向释放点并弹出 5 列「插入图形」面板；悬停或用方向键浏览图形时，在落点预览虚线轮廓与连线；选择后新节点贴住释放点、保持拖出方向，并与连线一起提交。Esc、点击面板外、窗口失焦、Pointer Cancel、第二根手指（双指缩放）、切换工具或源对象失效时全部撤回，零数据改动。

拖到对象上时按磁吸判定（靠近任一边即算命中，触控半径更大）。

每次创建只调用一次 `mutate`：节点与连线共用一条撤销记录，重做恢复相同 ID。新节点放在源对象该方向的同层空位，碰撞时沿垂直方向错开并逐级加大间距，只选择连线可路由的位置，从不推动已有对象；包含其他对象的底板矩形不视为障碍。附近没有合法空位时提示用户，不保存半成品。容量仍受 1000 个对象 / 10000 条连线限制。

流程图文字在形状的安全区内换行；超出时在图形内渐隐、悬停提示「拖动手柄可扩大」，编辑时显示全文，不越过轮廓。

流程图文字双击编辑：Enter 完成、Shift+Enter 换行、Esc 取消，输入法组合中按 Enter 不会提交。「样式」面板可在 25 种形状间切换（保留尺寸、文字与连线，端口随新轮廓更新），并设置描边颜色与宽度（0.5–10，超出自动收紧）；选中时仍显示自定义描边。

形状注册表 `flow-shapes.js`（`window.CanvasFlowShapes`）定义 25 个 `flowShape` 的稳定 ID、名称、默认尺寸、静态轮廓路径、文字安全区和真实轮廓端点；面板另含「文本」「圆形」两项，分别创建普通 `text` / `ellipse` 节点。端点取中心射线与轮廓的交点，矩形、胶囊、圆形和菱形仍是四边中点；连线端口与圆点共用同一函数。避障按外接矩形计算。工具栏「流程图」与右键「流程图」使用同一个网格面板。

节点可选字段 `strokeColor`（`#RGB` / `#RRGGBB`）与 `strokeWidth`（0.5–10），JS 与 Python 校验一致；不接受外部 SVG、HTML 或任意 CSS。交互由 `flow-quick-create.js`（`window.CanvasFlowQuickCreate`）实现。两个脚本都是必需编辑器资源：模板升级会一并安装，Portal 在 `runtimeVersion < 49`、`editorVersion < 19` 或缺少这两个全局时自动修复，且不改动 `canvas-data.js`、`boards/` 与 `assets/`。

验证：`node --test tests/canvas-flowchart.test.mjs tests/canvas-editor-upgrade.test.mjs`、`node tests/canvas-flow-quick-create.browser.mjs`、`node tests/canvas-flowchart.browser.mjs`、`python3 -m unittest tests.test_canvas_store`。

连线编辑器 20：调整连线配色或实线/虚线预设后，当前编辑会话中新建的普通连线与流程图快捷连线沿用最近设置的完整样式；选择其他连线不会覆盖该设置。

### 通用属性面板（运行时 50）

保存状态统一位于左下角；工具栏按实际尺寸避让；菜单分组显示细分隔线。属性面板提供图形选择、浮层下拉、统一圆形色板和数值拖动（Shift 加速、Alt 细调、Esc 取消），一次拖动对应一次撤销。Portal 将旧版无限画布自动升级到运行时 50；有未保存修改或恢复草稿时延后升级。升级只替换编辑器资源并保留备份，不修改布局、内部画板、素材和标注。所有新建画布直接使用此模板。

文本中的 fenced `mermaid` 代码块在画布和展开预览中渲染为 SVG；复用 PRD 的 Mermaid 渲染逻辑，编辑交互保持画布自身方式。`canvas-mermaid.js` 按需加载并随页面自包含，可离线分享；从 PRD 渲染源码更新后运行 `node scripts/build-canvas-mermaid.mjs` 重新打包。语法错误显示原代码，异步完成后重新测量文本高度。

普通文本（双击创建或粘贴文字）支持 Markdown / Mermaid 渲染、无格式工具栏，双击直接在框内编辑；Enter 原生换行，点击外部保存。拖入的 Markdown 文件（`markdownDocument: true`）或关联 PRD 额外提供文档编辑工具。输入框中的鼠标操作不进入画布移动手势。

普通文本框原位编辑支持列表 Enter 续写（有序编号递增、任务状态重置），空项逐层退级 / 退出；Tab / Shift+Tab 整行或多行缩进 / 退级，Shift+Enter 直接换行。代码围栏内不续写列表。保持无工具栏、无弹窗。

后台恢复固定状态时，页面更新后已删除或类型变化的控件自动跳过，继续恢复匹配控件。自动恢复异常只在该画板固定图标的提示中说明，不弹全局通知、不删除或重写已有固定状态；用户主动固定或更新时仍严格验证完整恢复并反馈失败。

### 控件交互（运行时 59）

隐藏独立「形状」创建入口（主工具栏、右键菜单、命令面板与快捷键），已有矩形和圆形仍正常显示、编辑。便签和其他非流程图对象点击快捷箭头统一打开流程图选择面板，选定后一次性创建节点和连线。

填充、描边和文字颜色复用连线的圆形色板：点击预设立即生效并关闭，彩虹入口可自定义颜色、实时预览，一次调整对应一次撤销。颜色控件共用 `CanvasCore.colorGrid`。

选中工具栏保持水平，固定在对象上方或下方并为快捷箭头留出间隔；避让不会再把它移到远处空位。

运行时 60：选中工具栏的颜色入口直接显示当前颜色圆点，复用连线的颜色按钮，不再显示「填充」文字或油漆桶图标；点击圆点打开统一色板。

运行时 61：便签、流程图和连线的颜色入口，以及属性和右键菜单的颜色入口，统一使用颜色圆点；选色和撤销后显示当前颜色。Portal 同时检测 `colorControlVersion`，避免版本号已更新但旧按钮未替换的页面被误判为最新版。
